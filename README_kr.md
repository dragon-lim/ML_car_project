# 라인 트레이서 (Line Tracer) — 진행 상황

1학년 강의실 실내에 설치된 라인이 아니라, **야외에 테이프로 설치한 라인**을 따라가는
자율주행을 목표로 한 프로젝트입니다. 야외 환경이라 햇빛·그림자·반사 등 변수가 많아,
상대적으로 빛이 안정적인 **일몰 전후 약 2시간**만을 작업 시간으로 정해 촬영 및 주행
테스트를 진행했습니다.

### 8/13~8/14

### 8/14~8/19
"테스트 정확도(test_acc)가 높은 모델일수록 실주행도 좋다"고 볼 수 없는 역설적인
현상을 확인. 특히 test_acc 49.83%였던 모델이 오히려 이전 모델들보다 실주행에서
차선을 크게 벗어나는 결과를 보임. 원인을 조사하기 위해 다음을 진행:

- 촬영 데이터에 **좌우반전·밝기조정·회전·이동** 을 적용하는 리샘플링(resampling, 오버샘플링) 도입
- 같은 장면이 연속된 다수 프레임으로 중복 촬영되어 있던 데이터를 클러스터 단위로
  정리하는 방식 구축
- 테이프 색상(초록·노랑)을 이미지 처리로 검출하여, 사진에 찍힌 실제 차선의 기울기를
  기하학적으로 계산한 뒤, 그 결과가 라벨(조향각)과 실제로 일치하는지 검증하는
  자체 도구(`label_check_v3.py` 등) 개발
- 검증 결과, 주행 중 차선을 벗어났을 때의 수동 조작 등이 원인으로 추정되는
  **라벨 오류**가 일정 수 존재함을 확인. 확신도가 높은 오류 패턴만 자동으로
  재라벨링하는 파이프라인을 구축했고, 서로 다른 3개 촬영 배치에 적용한 결과 모두
  라벨 오류가 약 80% 감소하는 걸 확인함

### 8/21~9/2
라벨이 수정된 데이터와 리샘플링된 데이터를 활용해 여러 차례 재학습 및 실주행 테스트를
반복. 오프라인 오버샘플링(리샘플링, 4배 증량)을 적용한 배치에서는 test_acc 61.76%를 기록하는
등 개선이 있었으나, 여전히 클래스 불균형과 라벨 품질 편차가 완전히 해소되지 않아
실주행 안정성에는 아직 과제가 남아있음을 확인. 코스 자체도 일부 보수하여, 보수된
코스에서 새로 데이터를 재수집하고 기존 데이터와 통합한 뒤 재학습·실주행 테스트를
계속 진행 중.

## 현재 상태

학습 파이프라인(데이터 수집 → 품질 필터링 → 라벨 검증·수정 → 학습 → TensorRT
변환 → 실주행 테스트)은 일련의 과정으로 구축 완료. 앞으로는 실주행 안정성 향상
(차선 이탈 시 대응 개선, 클래스 불균형 추가 보정)을 중심으로 계속 작업할 예정.

## 향후 계획

현재는 조향각을 30/60/90/120/150도 중 하나로 고르는 **분류(classification)** 방식으로
학습하고 있는데, 이 경우 모델이 5단계 각도 중 하나를 딱 잘라 예측하다 보니 실주행에서
조향이 계단식으로 뚝뚝 끊기는 경향이 있었다. 앞으로는 **회귀(regression, 선형회귀)**
방식으로 학습 방법을 전환하여, 모델이 "87도", "112도"처럼 연속적인 각도 값을 직접
예측하도록 바꿀 계획이다. 이를 통해 조향 전환이 훨씬 자연스럽고 부드러운 주행을
구현하는 것이 목표다.
